# Goblin Adoption Registry

The public list of adopted goblins for [Dig Too Deep](https://store.steampowered.com/) by Punch Up Games.

`ledger.csv` and `manifest.json` are generated and pushed by CI from the game's repository. Do not edit them here; changes will be overwritten. The game reads `manifest.json` and downloads `ledger.csv` only when its `version` (the file's sha256) changes.
